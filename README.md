## 🎮 About the Game

Ultrapool is a colorful single-player roguelike pool game developed by Icedrop Games and released on August 24, 2026. It combines arcade billiards with deck-building, shop management, and strategic run progression.

---

## 🔥 Project Overview

**This tool** is a comprehensive trainer for **Ultrapool**. This trainer enhances Ultrapool's single-player runs by providing control over shots, score, money, shop progression, and run difficulty. It is designed around the game's core systems: pocketing unusual balls, building synergies, purchasing upgrades, and surviving ten rounds.

**Target Audience:** Players who want to practice trickshots, test unusual ball synergies, explore the shop and cocktail systems, or experiment with complete roguelike builds without normal run restrictions.

> **⚠️ IMPORTANT:** This tool is for **educational and private use only**. It does not modify any game files — all changes are temporary and reset when the game closes. The tool is **undetectable**, but **use it at your own risk**. Always back up your save files before use.

## ⚡ Features (v1.0)

### 🎯 Gameplay

- **Unlimited Shots** — Prevents the current round from running out of available shots.
- **Add Score** — Adds score during a run to help reach round targets and activate score-based rewards.
- **Score Multiplier** — Applies a configurable multiplier to score earned from pocketed balls.
- **Easy Cocktail Mixing** — Supports experimentation with the cocktail bar's ball-mixing system.

### 📌 Progression

- **Add Money** — Adds bar currency for purchasing and improving balls and buying snacks between rounds.
- **Freeze Round Progress** — Prevents the current round from advancing while experimenting with a ball build.
- **Shop Refresh** — Refreshes available shop choices without requiring a normal run progression step.
- **Unlock Ball Collection** — Unlocks available ball sets and their unusual effects for collection-focused play.
- **Unlock Snacks** — Makes run-modifying snacks available for testing different builds.

## 📖 Detailed Feature Guide

### Movement & Exploration

Ultrapool has no character movement system. Gameplay movement is limited to aiming and controlling the cue shot. Use Unlimited Shots while practicing angles, rebounds, and trickshots without the usual shot limit.

### Tools & Inventory

The game's run inventory consists primarily of selected balls and snacks. Money can be used between rounds to buy or improve balls and purchase run modifiers. Unlock features are useful for testing collections and comparing different combinations.

### World & Environment

Each run takes place across a sequence of pool rounds with increasing score requirements. Pocketed balls generate score, score contributes to earnings, and the bar shop provides new balls, upgrades, snacks, and cocktail combinations. Use the trainer after entering a run and avoid changing progression values during transitions between rounds.

### Combat & Weapons

Ultrapool has no combat. Its challenge comes from managing shots, pocketing balls efficiently, handling special ball effects, meeting score thresholds, and building synergies strong enough to survive ten rounds.
